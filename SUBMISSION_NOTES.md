# Internship Submission Notes

Task: Simple Calculator

Technologies:
- Python 3
- Command Line Interface (CLI)

Main Python concepts used:
- Variables
- input()
- float()
- if / elif / else
- Functions
- try / except
- Arithmetic operators

The calculator accepts two numbers and an operation, performs the calculation,
and displays the result. Invalid numeric input, invalid operations, and
division by zero are handled safely.

To run:
python main.py
