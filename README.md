# Simple Calculator - Python Internship Task 1

## Project Description
This project is a simple command-line calculator developed in Python.
It performs the four basic arithmetic operations:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

The program takes input from the user and displays the result clearly.

## Internship Requirements Covered
1. Performs basic arithmetic operations.
2. Takes user input and displays results clearly.
3. Handles invalid inputs using try/except.
4. Specifically handles division by zero.
5. Contains comments explaining the different parts of the code.

## How to Run

### Requirement
Python 3.x

### Run the program
Open a terminal/PowerShell in this folder and run:

```bash
python main.py
```

## Example

```text
========================================
        SIMPLE CALCULATOR
========================================
Enter first number: 20
Enter second number: 5
Enter operation (+, -, *, /): /

Result: 4.0
```

## Error Handling Example

```text
Enter first number: 10
Enter second number: 0
Enter operation (+, -, *, /): /

Error: Division by zero is not allowed.
```
